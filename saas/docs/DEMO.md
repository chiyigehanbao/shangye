# FlowDesk 5 分钟演示脚本

> 目标：在面试或客户演示中，用一条完整链路说明“这不是四个 Demo，而是一个商业级 SaaS”。

## 0. 开场（20 秒）

打开落地页 `http://127.0.0.1:8000/`：

- 定位：**AI 办公自动化工作台**，四个模块共享账号、工作区、配额、审计与 AI 能力。
- 强调：单进程 + SQLite + Nginx，可部署在 2 核 2G 服务器。
- 点击右上角主题按钮，展示深/浅色设计系统。

## 1. 登录演示工作区（20 秒）

进入 `/login`，点击“演示账号一键登录”（`demo@flowdesk.dev / Demo@12345`）。

讲解：

- 数据库持久化会话，服务重启不掉登录。
- 当前工作区“星野工作室”，角色 owner，套餐 Pro。
- 顶栏显示 AI 通道与本月用量；侧边栏可切换工作区。

## 2. Dashboard（30 秒）

进入“工作台”：

- 四个模块的任务计数、本月运行次数、AI 调用次数。
- 近 14 天用量曲线。
- 最近活动混合展示 Excel、文档、报价、分析记录。
- 指出套餐用量卡：任务次数 / 存储 / 成员都有配额。

## 3. Excel 清洗（70 秒）

进入“Excel 清洗”：

1. 上传 `samples/excel-sales.xlsx`（或 `excel-sales.csv`）。
2. 指出自动识别的列与建议的“日期 / 门店 / 金额”。
3. 勾选“去除空行”“去除重复行”。
4. 分组列选“门店”，数值列选“金额”，聚合选“求和”。
5. 在 AI 指令框输入：`按门店汇总金额`，点击“生成汇总”。
   - 结果会显示结构化计划与 provider（无云 Key 时为“规则引擎”）。
6. 点击“开始清洗”，展示清洗前后行数、重复行数、汇总表。
7. 点击“导出结果”，得到两个 sheet 的 XLSX。
8. 切到“历史任务”，说明任务已持久化、可回看。

一句话总结：**上传 → 清洗 → 自然语言汇总 → 导出 → 历史，全部在一个工作区里完成。**

## 4. 文档字段抽取（70 秒）

进入“文档抽取”：

1. 在单文件区上传 `samples/contract-demo.txt`。
2. 字段填：`甲方,乙方,合同编号,合同金额,签订日期,联系电话,电子邮箱`。
3. 点击“开始抽取”，展示字段值与来源。
4. 切到“批量队列”，一次上传多份合同（可复制 `contract-demo.txt`），设置优先级。
5. 展示任务状态：pending → processing → done；说明支持失败重试、取消、断点续跑。
6. 勾选记录，导出横向表格。

讲解技术点：

- 原始文件按 SHA-256 去重存储。
- 任务写 SQLite，进程重启后可继续。
- 单 worker 是 2C2G 的主动取舍，不是遗漏。

## 5. 报价单（60 秒）

进入“报价单”：

1. 打开种子报价“星野咖啡 · 官网与数据工具”。
2. 修改某条数量，展示小计、折扣、税额、总计实时变化。
3. 点击“打印预览”，展示专用纸张样式（可浏览器打印为 PDF）。
4. 点击“AI 生成条目”，粘贴 `samples/quote-brief.txt` 的内容。
5. 说明金额由服务端重算，前端只负责展示。

## 6. 销售看板（60 秒）

进入“销售看板”：

1. 上传 `samples/sales-dashboard.csv`。
2. 接受自动识别的日期 / 城市 / 销售额。
3. 点击“开始分析”，展示总销售额、订单数、客单价、最高单日。
4. 展示趋势折线图与城市占比图。
5. 点击“生成 AI 洞察”，展示 3–5 条经营建议与 provider。
6. 导出 XLSX / CSV；打开历史分析。

## 7. 计费与团队（40 秒）

进入“计费”：

- Free / Pro / Team 对比，月付/年付切换。
- 当前 Pro 用量、发票记录。
- 说明这是**沙箱计费**：不接真实支付，但订阅 → 发票 → 配额变化 → 取消的闭环真实可验证。

进入“设置”：

- 成员列表与角色；邀请链接绑定邮箱、7 天过期。
- 审计日志；外观主题。

## 8. 平台后台（30 秒）

退出，用 `admin@flowdesk.dev / Admin@12345` 登录：

- 平台概览：用户、工作区、套餐分布、MRR、任务量、DB 大小、worker、AI 状态。
- 用户管理、工作区套餐调整、全局审计、健康检查。
- 强调平台管理员与租户管理员分离，普通用户访问返回 403。

## 9. 收尾话术（20 秒）

> FlowDesk 的核心不是“做了四个页面”，而是把四个高频办公场景收进一套可部署的平台：统一账号与工作区、真实配额与计费闭环、可降级的 AI、可追溯的审计、以及能在 2C2G 上跑起来的工程取舍。

## 备用：现场重置数据

```bash
cd saas
python -c "import os; [os.remove(p) for p in ['data/flowdesk.db','data/flowdesk.db-wal','data/flowdesk.db-shm'] if os.path.exists(p)]"
# 重启服务，自动重新 seed
```

或 Docker 环境：

```bash
bash scripts/reset_demo.sh
```
