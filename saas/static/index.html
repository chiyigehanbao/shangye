可以。推荐的单体部署只启动 1 个 FastAPI 进程、1 个 SQLite 和 1 个 Nginx，常驻内存约 700–900 MB。文档、报价、看板共享同一个后端，不需要为每个模块单独开服务。建议加 2–4 GB swap。
三层降级：云端 OpenAI 兼容 API → 本地 Ollama → 确定性规则引擎。任何一层失败都会自动落到下一层，界面会标注本次结果来自哪条通道，流程不会中断。
模块边界清晰：每个模块一个 router + 一个 service，数据库集中在一层。替换业务字段或新增模块不需要动认证、计费、审计这些平台能力。
